# TBRM v1.0（GitHub Pages）

正式頁面載入後會讀取已發布的官方快照，並在開啟的分頁每五分鐘檢查日期或更新狀態。Refresh 會立即重新讀取快照。

## 市場快照排程

- 平日台灣時間 14:30、17:15、23:15 保留，15:07、16:37、20:43 為備援。可從 Actions 手動執行。正式寫入只在預設分支執行，並序列化相同分支的執行。
- 以台灣時間 13:30 和版本化市場休市表推算預期交易日，再核對證交所 FMTQIK 實際成交日、收盤指數與 STOCK_DAY_ALL。月報及股票資料會在未備妥時重試兩次。若臨時停市未列入日曆，缺少當日官方成交報表會先保留快照並警告，待官方日曆修訂後更新休市表。
- `STALE` 會保留最近一次有效快照並發布檢查結果，Actions 顯示失敗。核心日期有效且來源完整時標記 `VALID`，核心日期有效而部分來源缺失時標記 `PARTIAL`，詳列缺失來源，網站按同日資料及既有規則計算可評分權重。下載狀態與日期核驗在 `data/market_update_status.json`，網頁另顯示實際計分完成度。
- 期交所 Put/Call 優先核對成交量及報表日期，可改取官方指定日表；外資期貨顯示和計分共用指定日淨未平倉。融資補齊只取指數最近 21 個交易日，維持率使用同交易日可對帳的融資報表。晚間備援處理來源延遲。
- 首次部署新版頁面後，正式 GitHub Pages 網址直接讀取此公開倉庫的 main 快照。Actions 之後用工作流程權杖提交行情時，網站讀取資料可獨立於 Pages 重新建置。
- 休市表的來源與年份存於 `data/market_calendar.json`。跨年度前加入新公告，資料檢查遇到未知年份會告警。

## 限制
- 官方快照中，上市個股漲跌家數僅在交易日一致且有效樣本充足時顯示；使用單日個股漲跌比例作為暫定廣度指標，尚非正式歷史 ADR。
- 櫃買漲跌幅僅在同日且辨識到明確百分比欄位時顯示。
- VIX、跌停家數、外資現貨與融資餘額變化仍未完成解析，顯示缺值。
- GitHub Pages 的 Refresh 讀取最新已發布快照。要請伺服器重新擷取，使用 Actions 的 Run workflow。
- 未實測 iPhone Safari 及線上官方 API；分數門檻仍未回測驗證。
